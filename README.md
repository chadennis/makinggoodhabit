# 도전! 한자 · 세계사 퀴즈

구몬 한자 B단계, 대한검정회 5급 한자, 세계사 퀴즈 사이트입니다.
빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 문제 수정하기
`index.html` 안의 `<script>` 맨 위 "문제 데이터" 부분을 고치면 됩니다.
- `B`: 구몬 B단계 90자
- `G5`: 5급 150자
- `SIM`, `COMBO`: 모양 도전 문제
- `W`: 세계사 문제 `[질문, 정답, [오답3개], 해설]`

## GitHub Pages로 배포
1. 이 폴더의 파일을 새 저장소(repository)에 올립니다.
2. 저장소의 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save.
3. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 열립니다.
